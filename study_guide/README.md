# Study guide

Prep material for the SusCo26 poster presentation (Group 10).

Easiest way: open [Every_Token_Counts_Study_Guide.pdf](Every_Token_Counts_Study_Guide.pdf), GitHub shows it right in the browser. All Q&A answers and quiz answers are printed in it.

The interactive version (with a rehearsal timer for the scripts) is `index.html`. Download the repo (Code > Download ZIP, or clone it) and open `study_guide/index.html` in a browser. Keep the `assets` folder next to it, the poster images are loaded from there.

What's inside:
- the theory we all need to know, with sources (lectures, papers, our data)
- the poster explained section by section
- the code behind the numbers
- weak spots and how to answer them
- talk scripts with a timer: Mateusz 0-10 min, Filippo 10-20 min, Hazem 20-30 min
- Q&A practice and a quiz with the numbers to remember
